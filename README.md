# Write It Out

A minimal desktop writing app for getting thoughts out of your head.

Write freely as the text gradually disappears.

## Development

Install dependencies:

```bash
npm install
```

Start the application in development mode:

```bash
npm start
```

Run ESLint:

```bash
npm run lint
```

Check formatting:

```bash
npm run format:check
```

Format the code:

```bash
npm run format
```

## Tech Stack
